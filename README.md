# Overview
This is my personal website and visualization portfolio. It is built using **HTML, CSS, and JavaScript**, and hosted as a static site. The website includes:

- A **homepage** with my personal introduction, education, skills, experience, and contact information.
- A **visualizations page** featuring:
  - A **bar chart** showing the number of concerts I’ve attended per year.
  - A **creative SVG art piece** of floating “concert lights” generated with JavaScript.

# Technologies Used

- **HTML**: Page structure and content.
- **CSS**: Styling, layout, fonts, colours, and responsive design.
- **JavaScript**: 
  - `main.js`: Basic interactivity on the homepage (e.g., nav link hover effects).  
  - `vis.js`: All visualizations and creative SVG artwork.
- **SVG**: Graphics and data visualizations created dynamically with JavaScript.

# How to Navigate the Site

1. Open `index.html` in a web browser.
2. Use the navigation bar to switch between **Home** and **Visualizations**.
3. On the **Visualizations** page:
   - The **bar chart** shows yearly concert data.
   - The **creative SVG art** displays animated floating lights.
